# Blxck-Empire
Forex Trading Bot Creator is a powerful and user-friendly mobile and desktop application designed to help traders, developers, and investors build fully automated Forex trading bots—without needing to write complex code. Whether you're a beginner or a pro, this tool allows you to combine technical indicators, set trading rules, backtest strategies, and export bots compatible with popular trading platforms like MetaTrader 4 (MT4) and MetaTrader 5 (MT5).

Key Features:

Drag-and-Drop Strategy Builder: Create bots using indicators like RSI, MACD, Bollinger Bands, Moving Averages, and more.

Full Indicator Library: Includes trend, momentum, volume, and Bill Williams indicators.

No Coding Required: Intuitive interface lets you design logic visually.

Backtesting Engine: Test your bot’s performance with historical market data.

MT4/MT5 Integration: Export bots as ready-to-use Expert Advisors (EAs).

Live Preview & Debugging: Monitor how your bot would behave in real-time scenarios.

Multi-Timeframe Support: Build bots that read signals across different chart timeframes.

100% Strategy Control: Customize entry, exit, risk management, and lot sizing.


Ideal for traders who want to automate their strategies and gain an edge in the Forex market.
